Design a complete mobile-first Arabic health fact-checking app called "Nabeeh" (نبيه).

IMPORTANT:
This is a mobile application prototype, NOT a desktop website.

The app should feel similar to the modern feed experience of Twitter/X:
- vertical scrolling feed
- clean content cards/posts
- fast browsing
- clear interaction hierarchy
- bottom navigation
- users can discover and read posts quickly

However, DO NOT copy Twitter/X branding, logo, exact UI, or visual identity.
Create an original design for Nabeeh with a professional health journalism identity.

====================================

App name:
NABEEH
نبيه

"Nabeeh" means perceptive, alert, and sharp-minded in Arabic.

Brand personality:
- Trustworthy
- Professional
- Editorial
- Calm

- Evidence-based

Avoid:
- playful startup aesthetics
- excessive gradients
- excessive rounded cards
- cartoon-style graphics
- emoji-based UI

The application should feel like:
A trusted Arabic digital newspaper + medical fact-checking platform + modern social feed.

====================================
TYPOGRAPHY
====================================

The entire app is Arabic-first and RTL.

Use:
- Noto Serif Arabic for major editorial headlines
- IBM Plex Sans Arabic or Tajawal for body text, navigation, buttons, and UI

Use strong typography hierarchy.

Arabic text must be right aligned.

The interface should feel like a modern Arabic newspaper adapted to a mobile social-feed experience.

====================================
RTL
====================================

The entire application must use RTL layout.

- Arabic text aligned right.
- Navigation direction follows RTL.
- Icons and arrows should correctly reflect RTL.
- Back arrows should point correctly.
- Cards should have RTL information hierarchy.
- Bottom navigation should feel natural for Arabic users.
